# Blockchain-Based Academic Certificate Verification System

A secure and decentralized web-based platform designed to issue, manage, and verify academic certificates using blockchain technology. The system enables educational institutions to digitally issue certificates to students while ensuring authenticity, integrity, and protection against document forgery.

The platform utilizes blockchain to store certificate hashes and transaction records, creating a tamper-proof verification process. Students can access and share their digital certificates, while employers, organizations, and other verifiers can instantly validate certificate authenticity through a unique verification link or QR code.

## Key Features

* Secure certificate issuance by authorized educational institutions
* Blockchain-based certificate registration and validation
* Tamper-proof certificate records using cryptographic hashing
* QR code and public verification portal for instant certificate verification
* Student dashboard for viewing and managing issued certificates
* Institution dashboard for certificate issuance and administration
* Verifier portal for validating certificate authenticity
* Role-based access control (Administrator, Institution, Student, and Verifier)
* Certificate revocation and status management
* Audit trail with blockchain transaction references

## Technologies Used

* React.js for the frontend user interface
* Node.js and Express.js for backend services
* MongoDB for application data storage
* Ethereum Blockchain and Smart Contracts for certificate verification
* Hardhat for smart contract development and deployment
* JWT Authentication for secure access control
* Cloudinary for certificate image storage and management

## Objective

The primary objective of this project is to eliminate academic certificate fraud by providing a transparent, secure, and decentralized verification system. By leveraging blockchain technology, educational institutions can issue trusted digital credentials, while employers and other stakeholders can verify certificates quickly and confidently without relying on manual verification processes.
